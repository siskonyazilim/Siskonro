# Local Font Files

The typography system is wired to these exact files:

- `public/fonts/belfast/`
  - `BelfastGrotesk-SemiExpanded.ttf` (400)
  - `BelfastGrotesk-MedSemExp.ttf` (500)
  - `BelfastGrotesk-SemBdSemExp.ttf` (600)
  - `BelfastGrotesk-BoldSemExp.ttf` (700)

- `public/fonts/lufga/`
  - `Lufga-Regular.ttf` (400)
  - `Lufga-Medium.ttf` (500)
  - `Lufga-SemiBold.ttf` (600)

Note: Prefer `woff2` for better performance when available.
